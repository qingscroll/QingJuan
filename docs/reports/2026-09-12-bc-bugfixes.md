| 编号 | 修复后的行为 |
| --- | --- |
| B1 | 图片下载失败或任务取消时，取消并等待同组子任务；已经开始的线程写盘结束后才退出维护闸，避免备份期间仍有孤立任务写文件。 |
| B2 | 章节下载完成时重新读取最新目录，只合并当前章节结果；不再用下载开始时的旧目录覆盖阅读期间缓存的其他章节。 |
| B3 | TXT 和无标题样式的 DOCX 保留首个章节标题之前的正文，作为“序章”保存。 |
| B4 | 内置管理员自助改密、邮箱重置不再返回临时成功；明确提示使用 `qingjuan-password` 修改部署密码。普通账号改密及会话失效流程保持有效。 |
| B5 | 已失效的阅读进度写入器忽略迟到的成功、失败、冲突响应；保留待同步操作供当前会话恢复，避免覆盖新的离线位置。 |
| B6 | 管理端忽略旧用户列表刷新，合并刷新期间已成功修改或新建的用户，避免界面状态倒退。 |
| C1 | 漫画重翻译先生成整章暂存结果，成功后成组发布；模型失败保留旧译文，发布失败回滚并保留可重试结果。历史缺失译图的章节在阅读和导出时回退到完整原图。 |
| C2 | 阅读器在目标正文加载成功后才提交原文/译文切换；失败保留原模式、正文和位置。 |
| C3 | 本地导入勾选“导入后翻译”会为全部导入章节创建翻译任务。任务创建失败时保留已导入作品，并提示在作品详情重试翻译。 |
| C4 | 模型状态被动查询返回相同配置的最后一次检查结果，不再因为 60 秒主动检查缓存过期就变为失败；配置变更及实际检查失败仍能反映。 |
| C5 | 手机与桌面本地导入增加文本编码选择。自动识别不能确定 GB18030、Big5、Shift-JIS 时要求选择，不再以第一个可解码结果静默保存乱码；UTF-8、带 BOM 的 UTF-16 自动读取。 |
| C6 | 插件账号书架导入的进度查询失败后，“重试”继续读取原任务；仅在没有任务 ID 时重新创建任务。 |
| C7 | 停止离线保存后刷新已提交章节和容量；最终提交前再次检查取消状态，未提交的新缓存被清理，旧缓存保留。 |
| C8 | 清理正在下载的书籍时撤销该下载操作，阻止迟到响应重新建立缓存；清理其他书籍不打断当前下载。 |
