# 质量与测试

## 1. TDD 流程

新增行为或修复缺陷遵循：

1. Red：写出能稳定复现需求的最小失败测试；
2. Green：实现使测试通过的最小改动；
3. Refactor：在测试保护下拆分职责、消除重复并改善命名；
4. Regression：运行相关测试、全量测试和真实 Windows / Android 构建。

测试应描述用户可观察行为，不绑定私有实现。缺陷测试在修复后长期保留。

## 2. 测试分层

### Dart 单元测试

覆盖：

- JSON 到 Model 的解析和默认值；
- 状态转换、筛选、排序和边界；
- Controller 成功、空、失败和重试；
- 后端地址、主题与偏好处理；
- 不依赖 Flutter 渲染的纯函数。

### Flutter Widget 测试

覆盖：

- Android 五入口底部导航和 Windows `NavigationPane` 分别覆盖窄宽度与常用宽度；Windows 变窄不得出现移动底栏，
  Android 变宽不得切换成 Windows 工作区侧栏；
- 加载、空、错误和内容状态；
- 表单校验、按钮禁用、对话框确认；
- 主题切换、系统返回和关键触控操作；
- 外观模式在 Windows / Android 使用正确的系统、浅色与深色图标及平台文案，图标具备语义标签；
- 长文本、文字缩放与不同手机/平板宽度。
- “书源管理”和“插件配置”必须保持两个资源。Windows 本机模式侧栏可分别到达两者；切换 Linux 远程模式时隐藏插件入口并
  将已打开的插件页回退到设置。Android 不显示插件入口。开关保存中不可重复点击，失败时恢复服务端状态并显示可操作错误。
- 插件配置覆盖名称 / 域名搜索、全部 / 已启用 / 已停用筛选、小说 / 漫画 / 通用分组、无匹配结果和详情元数据；Windows
  验证双栏选择、页面专属宽内容上限、清单 / 详情最小宽度和两套独立滚动控制器，Android 验证触控列表与详情入口。滚动条
  展开后不得覆盖条目状态或详情内容；筛选或选中状态不得改变后端插件开关。
- 账号型插件覆盖二维码加载、等待扫码、成功、过期与失败状态，以及 Cookie 登录成功、无效和立即清空输入；未登录或插件停用时
  书架导入不可用。批量导入交互覆盖处理中锁定、成功 / 已有 / 暂不支持 / 失败计数和完成后刷新书架，且任何 Widget 文本与异常
  都不得包含 Cookie、第三方 Token、上游二维码令牌或账号 ID。
- 搜索页覆盖默认“书源”、切换“夸克”“番茄”“起点”和“笔趣阁”、切换时清空旧结果、五种加载文案与统一加入书架载荷；手机窄宽度不得因引擎选择器、
  输入框和搜索按钮同排而溢出。Android 内置搜索结果加入书架必须覆盖异步链接任务的排队、完成、失败与按钮锁定，Windows 保持原有同步导入流程；网关 HTML 错误不得原样出现在提示中。
- Android 详情页在带状态栏安全区的窄屏上验证标题不与系统图标重叠；阅读器进入、控制层显隐和前台恢复都必须保持 Flutter `edgeToEdge`，并通过原生阅读通道传递阅读背景色，请求“隐藏顶部状态栏、关闭 decor 避让、允许刘海短边布局”。离开时恢复顶部状态栏。测试必须拒绝手动覆盖层和 `immersiveSticky`，验证阅读器背景覆盖完整窗口，并由 Android release 构建证明窗口获焦重应用、状态栏颜色和刘海策略代码可编译进入 APK。正文测试必须验证段首标记被转换成随 `TextScaler` 缩放的固定宽度布局占位而不是空白字符；除段落内部字形坐标外，还必须在与实际列表相同的 `Center + 阅读栏约束` 下断言短段和自动换行长段首字的页面全局横坐标一致，防止只给 `maxWidth` 导致短段收缩居中。正文保持两端对齐，换行续行与跨页续行不重复缩进。
- Android 阅读器音量键测试覆盖开关关闭时保留系统音量行为、开关开启后分页模式上一页/下一页、连续模式向上/向下约一屏，以及连续列表首尾只按一次即可补载相邻章节并继续移动；原生层只在首次按下时发送事件，同时消费对应抬起事件。
- Android 连接 Token 测试必须同时覆盖关闭放大镜但保留原生选区，以及显式“粘贴”按钮从纯文本剪贴板更新输入控制器；测试和日志不得输出剪贴板或 Token 内容。
- Windows 本机后端设置覆盖应用内模型表单的就绪 / 禁用状态、密钥替换与清除、保存后强制自检，以及 `/admin` 管理站点
  未挂载；测试不得真正启动浏览器。

测试必须显式提供 `MediaQuery`、主题和依赖，避免依赖开发机隐含环境。

阅读定位与任务重试还必须覆盖：分页退出重开仍为同章同页、字号和窗口变化后字符锚点落在恢复页内、Windows 与 Android 连续模式的章内逻辑页码、连续模式同章滚动和后台保存、长短段落混排时的远距离锚点恢复、初次加载失败不覆盖旧进度、慢请求串行合并、空队列刷新后的立即保存，以及账号/后端切换隔离。链接任务覆盖服务端已接受但响应丢失后的手动重试，并组合已有终态预览任务的场景。

### Python 单元与集成测试

部署回滚使用隔离目录在数据库及 WAL 备份中途注入写入失败，断言生产文件逐字节不变且旧服务可恢复；完整快照后的切换失败仍应恢复原数据。抓取回归必须模拟上游失败并断言旧正文保留，还要验证公网到内网重定向、混合 DNS 答案、DNS 重绑定及浏览器子资源的实际出站边界。

覆盖：

- 应用工厂和 Router 注册；
- Linux 注册策略、必填且唯一的邮箱、验证码过期/错误次数/一次性消费/发送与注册限流、身份牌组合校验、SMTP 密钥不回显、
  管理设置 CSRF 与并发 `keep` / `replace` / `clear` 合并，以及 Windows 单用户模式统一返回 `404`；
- GitHub Device Flow 固定上游地址、无 scope 请求、轮询间隔与 `slow_down`、过期 / 拒绝、绑定唯一性、未绑定禁止登录、管理员关闭后旧流程失效，
  并断言设备码、GitHub Token 与 2FA 密钥不进入数据库、响应或日志；
- RFC 6238 已知向量、时钟偏移、同时间步重放拒绝、TOTP 密文篡改、恢复码一次性消费、2FA challenge 过期 / 尝试次数 / 跨流程限流，以及
  密码登录和 GitHub 登录都必须在第二因素完成后才创建会话；
- API 状态码、校验与错误结构；
- 数据 CRUD、事务和迁移；
- 路径边界、URL 校验与内容解析；
- 站点插件注册表的稳定 ID、匹配优先级、默认状态与 SQLite 迁移；禁用后预览、章节抓取和内置搜索均不得发出第三方请求；
- 外部插件覆盖包预检不执行代码、格式/域名/版本冲突、管理会话与 CSRF、安装后真实预览/正文/图片/搜索、更新保留停用状态、失败保留旧包、重启恢复及损坏包隔离；SDK 校验重定向域名、输出链接和协作式超时取消。Flutter/React 覆盖包上传、安装/卸载反馈和切换后端的迟到响应。
- 夸克适配使用固定响应 Fixture 覆盖搜索映射、作品与完整目录解析、目录短时复用、429 / 临时网关错误有界重试、正文还原、非免费标记章节在正文端点返回完整内容时正常解析、非官方正文域名拒绝及插件停用短路；
- 番茄适配使用固定响应 Fixture 覆盖匿名签名搜索与结果过滤、二维码状态、Cookie 登录校验、作品与目录映射、书架条目去重、非文字作品、已有作品跳过和
  单本失败隔离；公开 API 断言不返回站点 Cookie、CSRF、上游二维码令牌或账号 ID，CI 不依赖真实登录账号；
- 起点适配使用固定移动站 SSR Fixture 覆盖搜索字段映射、作品链接规范化、二维码状态、目录访问标记、书架分页去重、VIP 标记章节在返回普通正文时正常解析，以及不支持的加密正文格式明确报错；搜索不得携带账号 Cookie，CI 不依赖真实登录账号；
- 任务状态与失败恢复；
- Linux 服务器托管章节缓存覆盖：仅写目录清单后立即按章节序号后台执行、客户端请求结束后任务仍存活、服务启动后从未落盘章节恢复、同章进行中任务合并、单章失败隔离，以及任意所选章节无需等待正在下载的其他后台章节；测试还必须证明后台下载全局并发为 1、阅读到来会中断并重新排队不相关的后台章节、当前章与下一章可同时准备、章节清单并发写回不丢更新，并且客户端在当前章响应前已经发起下一章预取。

- 无 Token、错误 Token、正确 Token、元数据版本与服务标识。
- 所有公开响应和错误都不包含数据目录、绝对路径或设置密钥。
- 导入上传、导出产物、认证下载、过期清理和路径穿越防护。
- Linux Chromium 与 RapidOCR 能力通过显式配置和探测暴露。

### 远程连接与 Linux 原生服务

- Dart 测试覆盖未配置、远程成功/失败、Token 安全读取和服务器切换清理，并证明不会启动本地进程。
- API 测试覆盖 JSON、multipart、图片和流式下载都携带正确认证头。
- 同源测试必须证明 Token 不会发送给第三方封面 URL 或跨源重定向。
- Bash 语法和原生进程冒烟测试验证 `/healthz`、认证元数据、可写数据目录、单 worker 与优雅关闭。
- systemd 单元必须通过 `systemd-analyze verify`，安装脚本不得把原始 Token 写入普通日志或进程参数。
- 管理认证测试覆盖正确/错误密码、限速、签名会话、HttpOnly/SameSite Cookie、CSRF、退出和改密后会话失效；
  日志与响应不得出现管理密码、会话签名密钥或客户端 Token。
- React 管理界面测试覆盖登录错误、会话失效、数据加载、写请求 CSRF、空状态和破坏性操作确认；生产构建结果
  必须与 `python-backend/app/admin_static/` 中提交的静态资源一致。
- Linux 插件管理测试覆盖 `#plugins` 深链接、名称 / 域名搜索、启停筛选、元数据展示、逐项保存锁定和失败反馈；API 客户端
  必须通过管理员会话与 CSRF 调用现有 `/api/v1/plugins`，不得新增浏览器侧插件状态副本。
- 设备管理测试覆盖首次登记与重复心跳、在线窗口、非法设备头、旧客户端兼容、管理会话权限、CSRF、封禁后 `403`、解封恢复，
  以及 Flutter 请求只向配置后端同源发送稳定设备标识。前端覆盖设备筛选、数量统计与封禁确认。
- 连接 Token 展示测试覆盖默认状态不返回原文、未登录拒绝、显示操作必须携带 CSRF、连接文件与摘要一致性、
  `no-store`、旧部署不可显示和前端 60 秒自动隐藏；任何失败响应与运行日志都不得包含原始 Token。
- 服务器运行日志测试覆盖 Uvicorn/应用/任务来源、级别与关键字筛选、轮转文件尾部读取、错误堆栈、自动刷新和
  二次脱敏；管理 API 不得读取任意路径、调用 shell 或暴露 journal 中其他服务的内容。
- 系统诊断测试覆盖管理员会话权限、普通 Bearer 拒绝、请求计数与 P95、数据库/任务执行器/磁盘检查、日志异常摘要、
  `no-store` 和进程级指标隔离。接口及前端下载报告不得包含环境变量值、凭据、正文或绝对路径；前端覆盖刷新、
  状态文案、异常空状态和脱敏报告下载。
- 翻译模型自检测试覆盖未启用、配置缺失、成功响应、认证失败、非 JSON、限流、网络异常、60 秒缓存和强制刷新；
  探针不得包含书籍正文，响应、日志和客户端错误不得包含 API 密钥、API 地址或供应商响应原文。Flutter 连接测试覆盖
  元数据后调用自检、自检失败仍可阅读、状态提示和无客户端模型回退；管理界面覆盖手动自检及保存后的强制自检。

  未保存 Linux 草稿在本次页面切换后仍然存在。图标变更后运行 `python tool/generate_app_icons.py`，检查 Windows ICO 包含
  多尺寸帧、Android 五档密度尺寸正确，并至少实机构建一次 Windows 与 Android。

## 4. 三轮验证

每项实现至少经过三个层次，而不是机械重复同一命令：

1. 静态轮：格式化、Analyzer、Ruff、TypeScript、依赖与敏感信息扫描；
2. 行为轮：Dart/Python/React 单元测试和 Widget/接口测试；
3. 产物轮：React 管理界面静态构建、Windows Release 与 Android Release APK 构建和安装，Windows 随包后端本机握手、
   Windows/Android 远程握手，以及切换和退出清理。

涉及后端或部署时，产物轮还包括 Linux 原生进程启动、systemd 单元检查、认证请求和 Android 到 Linux
的真实文件往返；不得用本机共享目录替代网络传输验证。

某轮失败时先修复，再从受影响的最早轮开始重跑。不得把“本地能打开”当作所有测试通过。

## 5. 性能

- 不在 `build` 中解析大 JSON、读文件或发请求。
- 大列表使用惰性构建；稳定 key 避免无意义重建。
- Controller 只通知真正变化的状态。
- 搜索输入使用合适防抖，用户提交操作不重复发送。
- 图片按显示尺寸解码并限制缓存；长章节避免一次创建过多 Widget。
- 后端所有外部请求有超时；下载与翻译并发有上限。
- SQLite 查询避免循环中的重复全表读取。

性能问题必须提供可复现数据：样本规模、硬件、操作、耗时与修改前后对比。

## 6. 完成定义

变更只有同时满足以下条件才算完成：

- 需求与边界明确，未引入手机本地后端或旧前端技术栈；
- 架构和命名符合规范，无新增巨型文件；
- 正常、空、错误、重试和取消/重复操作已考虑；
- 新行为有测试，旧行为无回归；
- 文档与命令同步；
- Windows / Android 远程连接、Linux 服务和认证边界均按变更范围验证；
- 三轮验证通过；
- `git status` 中无缓存、构建产物和无关文件；
- 不包含凭据、数据库、个人数据或受版权保护内容。
