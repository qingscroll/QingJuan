# 青卷移动端重构 · 2026-09-06更新

本次从作品、阅读进度和后台任务重新组织 Android 体验。实际入口已替换；Windows 继续使用 Fluent 桌面壳层，React 管理端没有界面改动。

## 信息架构

| 一级入口 | 主任务 | 二级路径 |
| --- | --- | --- |
| 书库 | 找回正在读的作品 | 继续阅读直达正文；裸封面网格；书库搜索、类型筛选、排序、批量管理 |
| 发现 | 在真实来源中找书 | 关键词 → 来源 → 结果 → 预览 / 加入书库 → 导入进度 |
| 任务 | 了解处理是否完成、如何恢复 | 下载 / 翻译 / 当前导入；阶段、章节数、真实进度、失败原因、后端重试 |
| 我的 | 管理个人偏好和访问权限 | 外观、声音、书源、账号安全、连接、翻译服务状态、关于 |

手机采用小液态胶囊底部导航，在 Scaffold 独立底栏内占位，不覆盖列表。胶囊最大宽度344dp、基础高度56dp，四个入口均保留至少48dp触控区域；系统文字放大时高度随之增加，底部遵循安全区。840dp 起使用可滚动的移动侧栏；作品详情在宽屏使用作品信息与目录并列。访问过的主页面保留状态，切换账号或后端会更换页面状态和滚动存储。

首次使用从书库直接进入服务连接，再到账号登录。已有会话自动恢复。连接验证、登录恢复、登录失效、断连和权限限制各有真实提示；断连保留已加载的书库。不会提供离线可用的假象：Android 内容仍通过服务端访问。

作品详情是连续的作品信息、原译状态和章节目录，底部保留开始 / 继续阅读。下载章节是服务端缓存任务；导出是保存文件到本设备，两者现在明确区分。大量章节按需构建并可查找、选择和批量操作。

## 视觉体系与实现入口

青瓷绿作为少量强调色，中性纸白与中性黑形成安静背景。深色独立使用近黑页面、深灰内容表面和更亮的内嵌表面，避免整页偏绿。正文和操作的层级通过文字、间距、表面明度与细分隔体现。

依照后续确认的方向，重新实现小液态胶囊导航：半透明表面、细边缘、轻微明度渐变和局部 sigma12 背景模糊共同表达浮层，仅应用于底部胶囊。选中态连续平移；减少动态效果时过渡为零，减少动态效果或高对比模式下均关闭模糊与投影。旧通用玻璃组件已移除，内容页继续使用稳定实色表面。

- 颜色：`lib/shared/mobile_palette.dart`，同时供移动 Material、Miuix 和移动 Fluent 兼容层使用；桌面主题独立。
- 几何与动效：`lib/mobile/mobile_tokens.dart`，4 / 8 / 12 / 16 / 24 / 32 间距，48dp 主要触控目标，12dp 控件、16dp 表面、24dp 面板圆角，160 / 240ms 反馈与过渡。
- 主题：`lib/mobile/mobile_theme.dart` 与 `mobile_app.dart`。页面标题24、分区16、正文14–16、辅助12–13，中文常规行高1.45。跟随系统 / 浅色 / 深色实时切换并保存。
- 页面与组件：`MobilePage`、`MobileCard`、`MobileSection`、`MobileSearchField`、`MobileBookCover`、`MobileOverlaySurface`、`MobileSettingsPage`、`MobileImportProgress`、`MobileActionButton`。
- 复杂连接、登录、注册、安全、书源编辑和导入使用完整路由；简短来源选择、排序、局部播放与阅读设置使用底部面板。
- 真封面使用认证正确的图片链路和解码宽度限制，缺省封面使用完整书名，深色降低图片亮度。没有额外安装 React 包或引入 WebView。

首页阅读入口调整为“接着读 ›”无底色行内操作。详情阅读、播放、导入、重试、登录和服务连接使用 `lib/mobile/mobile_action_button.dart` 的 `MobileActionButton`；按钮文字为14逻辑像素、w500字重、1.25行高，继承所在页面的中文字体和回退字体并跟随系统文字缩放。最小触控区域48dp、圆角10dp，常见操作使用轻薄实色表面与细边；图标与文字空间受限时允许文字换行。

常见操作按钮采用独立的中性灰填充、对应的深浅文字和细边，品牌强调色负责少量文字强调与选中反馈；页面的 #090909 / #151515 / #242424 黑色层次保持一致。次要操作使用 tonal 或描边样式，退出、删除与解除绑定保持原有操作层级。

忙碌状态绑定真实请求或播放状态，显示进度反馈并禁用重复触发；无法执行时明确呈现禁用样式。减少动态效果时按钮过渡为零，忙碌指示改为静态弧。组件为重要状态提供语义反馈，并保留原有文案、操作 Key 和业务回调。

针对安装包截图暴露的红色大字与黄色双下划线，`MobileQingJuanApp` 根 `Material` 明确设置正常正文样式：w400字重、`TextDecoration.none`及主题正文颜色。真实二级路由由此获得稳定的文字继承。详情、阅读器和移动列表的加载状态移除可视文字，仅显示28dp轻量进度环；原状态保留在 `Semantics` 中供读屏使用，错误说明与重试入口不受影响，Windows仍显示原有加载文字。

正文重新校准为默认19字号、标准1.65行距、0.85em段距、24dp左右边距和640dp正文最大宽度。保留用户已保存的字号等偏好。控制栏按需出现，阅读主题独立于应用主题，字号和排版调整恢复阅读比例；首次加载也会恢复已保存的位置。漫画单图加载、错误与重试就地显示，支持缩放和阅读位置恢复。

TTS 页面围绕章节、播放、进度与正在朗读的文字组织，语速、音量、原译文与声音入口真实可达。当前引擎生命周期为页面级，离开听书页会停止；没有伪造跨页面播放条。

## 真实能力与边界

| 能力 | 已连接的实际实现 | 约束 |
| --- | --- | --- |
| 服务连接 | meta 探测、连接 Token、安全存储 | Android 仅远程；没有本机后端回退 |
| 账号 | 注册策略、邮箱验证码、身份牌、密码登录、GitHub、TOTP / 恢复码 | 依服务器开放策略；敏感输入退出即清除 |
| 书库 | 共享 LibraryController / ApiClient | 书库摘要无作者字段，作者仅详情与搜索显示 |
| 搜索 | 我的书源、夸克、番茄、起点、笔趣阁 | 没有推荐、榜单或社交数据 |
| 导入 | 链接异步任务、本地文件上传、失败重试 | 链接任务没有取消接口；服务端解析阶段不伪造上传百分比 |
| 下载 / 翻译 | TasksController、真实0–100进度、失败重试 | 不提供没有实现的取消；已完成章节保留 |
| 导出 | 原有导出与文件保存链路 | 下载到服务端与保存到设备分开 |
| 权限 | 普通用户书源只读，管理员可维护支持的书源配置 | Android没有插件工作台和桌面漫画编辑器 |
| 模型 | 读取真实模型健康快照 | 强制模型自检依赖服务管理会话，移动端不假装能执行 |
| 阅读 | 小说分页 / 连续、漫画、原译、进度、系统TTS | 进度协议为比例，连续排版变化不能保证逐字锚点一致 |

当前链接导入 Controller 只追踪一条任务，任务ID不跨应用进程重启恢复；服务端完成后作品仍能通过书库刷新出现。任务和下载数据在服务端，不能将“已下载”解释为 Android 断网离线阅读。永久删除接口没有撤销能力，因此明确列出对象、已下载内容和阅读记录被删除的后果。

## 尚未完成的设备验收

环境没有连接 Android 设备，也没有可用 AVD。真实 Android 返回手势、系统栏、软键盘、长漫画帧率、原生文件选择 / 文件导出与设备TTS音色仍需要设备验收。外部站点搜索结果和成功的模型翻译需要可用测试服务及对应上游，本次没有接入个人远程账号或调用付费翻译服务。
