# 青卷 V2.1.0 更新日志

本版新增 Windows 漫画翻译工作台，并打通书架漫画与专属翻译流程。

## 漫画翻译工作台

- 新增侧栏“漫画翻译”，复刻正常翻译、导出译文、导出原文、仅翻译工程 JSON、导入译文并渲染、仅上色、仅超分、仅修复和替换翻译九种工作流。
- 支持批量选择图片、递归选择文件夹和拖放导入，并保留兼容的 `manga_translator_work` 工程目录。
- 支持停止批处理、逐文件查看状态和选择独立输出目录。
- 优化短语气词、感叹词和拟声词翻译；严格校验逐区域返回结果，模型漏项、重复项会整批重试，原样返回日文时只定向重试对应区域。
- 对连续无法翻译的裁切招牌或拟声片段保留原图并记录区域编号，其余有效译文继续渲染，避免单个区域导致整页失败。
- 修复 `ねー`、`はぁ` 等双字符对白被误判为装饰文字、最终没有嵌入译图的问题；纯标点和大型单字音效仍保留安全过滤。
- 修复旧工程重载后把紧 OCR 文字框误当成气泡框、导致纵排原文边角笔画没有盖住的问题；新工程会持久化气泡框、安全框和区域样式，单个平假名对白也会正常替换。
- 新增三栏文本修改工作台，可逐页核对文字框、修改原文与译文、切换横排/纵排，并筛选尚未翻译的区域。
- 支持在漫画原图上拖框新增人工区域，OCR 完全漏检的对白、标点和拟声词也可以手动补译。
- 人工保存后直接复用工程重新擦字与渲染，不再次调用 OCR 或翻译模型；普通字段修改会保留工程中的字体、颜色和其他扩展信息。
- 保存和渲染期间锁定编辑，返回时保留未保存修改；连续重渲染会立即刷新结果预览。
- 根据未修改原图提取真实气泡内域，擦字与嵌字共用轮廓限制，修复凹形、连接气泡突出白框、分镜线及人物被误擦的问题；旧工程只有 OCR 框时同样生效。
- 对无法可靠分离的气泡外网点字保留原图，避免局部擦花；已有译图需在文本工作台重新渲染后更新到书架译文，无需再次调用翻译模型。

## 书架联动

- 漫画书籍详情中的翻译按钮会自动把全部章节导入专属工作台；勾选章节后只导入所选内容。
- 工作台新增“从书架选择”，只展示漫画书籍，并自动获取原图章节。
- 书籍图片缓存在按后端与用户隔离的本地目录中；重复导入不会删除已有翻译工程。
- 书架来源任务会保留精确的书籍、章节和页码绑定；整章成功后，译图、逐页区域元数据和章节译文会直接发布到书架“译文”。
- 写回采用整章完整性校验和可回滚发布；单页失败不会生成缺页章节，其他已完成章节仍可独立写入。
- 文本工作台重新渲染书架页面后会自动重组完整章节并更新书架译文；缺少其他页面时只保存本地工程并提示待补页面，不发布残缺章节。
- 已修改但尚未重新渲染的页面会持久标记为待处理，避免新译文与旧结果图一同写回书架。

## Windows 窗口体验

- 修复自绘窗口控制栏右侧留白，最小化、最大化和关闭按钮现在完整贴合窗口右边缘。
- 窗口控制栏提升为全局窗口框架，进入作品详情、阅读器及更深层页面后仍持续显示。
- 新增“收起到托盘”按钮，隐藏窗口后下载与翻译继续运行；点击右下角青卷托盘图标恢复，右键菜单可显示或退出青卷，原有最小化与关闭行为不变。
- 托盘恢复保留最大化状态，系统任务栏重建后重新注册图标；注册失败时保留或恢复可见窗口，避免程序隐藏后无法找回。
