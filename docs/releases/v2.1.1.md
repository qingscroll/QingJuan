# 青卷 V2.1.1 更新日志

本版集中修复 Android 移动端实际二级路由中的文字样式继承与视觉反馈问题。

## 移动端显示修复

- 修复从真实移动端应用进入作品详情和阅读器时，部分文字继承框架回退样式，出现异常红色大字、黄色双下划线或错误字重的问题。
- 分页与连续阅读正文显式恢复正常字重、字形和文字装饰，同时保留用户保存的字号、行距、主题与阅读位置。
- 作品详情、章节打开和列表加载在移动端改为轻量进度环，不再重复显示加载文字；状态仍通过实时语义标签向读屏软件播报。
- Windows 桌面的加载文字和既有反馈行为保持不变。

## 交互与视觉

- 移动端常用操作按钮改为更克制的中性灰层级、标准字重和较小圆角，深浅主题同步调整。
- 书库“接着读”改为行内操作，并针对窄屏和较大系统字号自动换行，避免与阅读进度拥挤。
- 更新移动端设计截图，新增真实应用路由下详情、分页阅读和连续阅读的加载及内容状态。

## 回归覆盖

- 测试不再用额外的 `FluentApp` 包裹移动根应用，避免测试主题掩盖真实路由的文字继承问题。
- 新增从 `MobileQingJuanApp` 打开作品详情、分页阅读和连续阅读的深浅主题回归测试。
- 新增加载状态的可见内容、实时语义标签及 Windows 行为测试。

## 版本

- 应用版本：`2.1.1+41`；预期发布标签：`v2.1.1`。
