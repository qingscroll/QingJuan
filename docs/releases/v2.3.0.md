# 青卷 V2.3.0 更新日志

本版集中完善书库整理、跨端阅读、内容维护和服务端运维能力，并加强长任务、文件发布与账号资源之间的安全边界。

## 书库、发现与导入

- 新增站点发现页，可浏览推荐栏目和排行榜、分页查看作品，并在正式导入前预览作品信息与章节。
- 书库支持分组、标签、置顶和阅读状态，可编辑书名、作者、简介与封面；筛选、搜索和排序在 Windows 与 Android 上保持一致。
- 新增连载追更，支持手动检查、定时检查、未确认更新标记及按需自动下载，并保留已有章节和阅读位置。
- 增加链接导入历史与可恢复的任务状态，改进本地 TXT、DOCX、EPUB、PDF 导入的编码识别、错误反馈和持久化。

## 阅读、离线与听书

- 新增书签、划线笔记、章内搜索及已缓存正文的全书搜索；笔记按账号隔离，并在正文变化时避免错误定位。
- Android 支持选择章节保存到设备离线阅读；待同步阅读进度持久保存，恢复联网后自动提交，跨设备冲突由用户明确选择。
- 阅读进度写入增加版本与幂等保护，避免重试、迟到响应或并发设备覆盖更新的位置。
- 听书支持独立位置恢复、定时停止，以及 Android 通知栏和锁屏媒体控制；应用进入后台后继续保持播放状态。
- 优化连续与分页阅读、漫画图片加载、章节切换和大字体布局，并统一启动画面与主题配色。

## 翻译与插件

- 小说新增每书术语表、人名映射、译文校对、历史版本、恢复及选段重译，并记录模型用量。
- 普通章节翻译与交互校对共用版本保护和原子发布流程，源文变化、并发编辑或文件写入失败时不会静默覆盖现有译文。
- 插件管理新增自检、兼容性检查、安装包导入、版本维护与回退；登录流程和站点账号状态提供更明确的诊断。
- 加固模型端点、站点抓取、公开 DNS、重定向和 Fake-IP 环境的网络边界，避免请求进入本机或内网保留地址。

## 备份、存储与管理

- 新增完整书库备份、校验和恢复，并支持将 Windows 本机书库显式迁移到空的 Linux 服务端；恢复过程包含路径、归属和中断保护。
- 新增书籍占用统计与导出文件清理；用户存储额度和模型请求额度由服务端统一执行，超额时保留既有文件。
- 下载与翻译任务按账号公平调度，管理后台可查看和控制任务、维护插件、管理备份，并刷新用户资源用量。
- 账号页新增自助改密、验证邮箱找回密码和登录会话管理；切换账号或后端时清理旧身份的缓存状态与迟到响应。

## 升级说明

- 更新前建议先备份当前书库。Windows 在线升级和覆盖安装继续保留 `backend/data/`；Linux 请同时保留 `/var/lib/qingjuan` 与后端环境配置。
- 新能力由后端能力标志协商。为获得完整功能并避免旧端缺少接口，远程部署建议客户端与 Linux 后端一并更新。
- Android 离线副本不替代服务端书库；清理离线缓存会保留尚未同步的阅读进度。

## 版本

- 应用版本：`2.3.0+44`；预期发布标签：`v2.3.0`。
