# 青卷 V2.0.2 更新日志

本版聚焦移动端阅读体验稳定性与流畅度，重点优化翻页性能，并修复偶发书页异常。

## 关键修复

- 修复阅读器偶发出现“大片空白页”的问题：分页策略改为更稳健的边界裁切，加载下一章时优先保留当前页内容。
- 解决跨章节预加载场景下的页面抖动与“翻页卡顿”：
  - 减少了高开销的全页透明/渐隐动效；
  - 复用分页与列表构建缓存；
  - 限制部分场景下图片解码尺寸，降低内存抖动。
- 将连续阅读中的长列表渲染与部分状态刷新路径解耦，降低频繁重建造成的掉帧。
- 优化章节切换与分页索引回正机制，避免加载失败时停留到不存在内容页。

## 版本

- 应用版本：`2.0.2+34`；预期发布标签：`v2.0.2`。
