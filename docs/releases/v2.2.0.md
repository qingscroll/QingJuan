# 青卷 V2.2.0 更新日志

- 每次启动独立检查 GitHub Releases 正式版，不依赖后端连接或登录状态；发现新版显示可关闭的提示。
- 更新源、下载地址校验与关于页统一使用迁移后的 `qingscroll/QingJuan` 仓库，修复检查更新误报网络失败的问题，并区分发布信息异常与连接错误。
- Windows 设置页增加当前版本、检查更新、更新说明、下载进度、取消重试和退出安装入口。
- 下载 Windows 安装包时校验发布文件名、大小和 SHA-256，安装前再次校验；校验失败不会运行安装包。
- Android“我的 → 软件更新”支持检查版本和在浏览器中下载 APK，安装由系统处理。
- 增加 Windows x64 安装包，默认按当前用户安装，提供开始菜单、可选桌面快捷方式和卸载入口。覆盖升级及卸载保留 `backend/data/`。
- Windows 后端改为目录式打包，移除未使用的视频、GUI 与自测依赖，采用统一压缩，安装包缩小约 32%；保留离线 OCR 模型及现有图片格式支持，启动时不再反复解包。
- 发布流水线同时提供 Windows ZIP、Windows 安装 EXE、Android APK，以及各自的 SHA-256 文件。

应用版本：`2.2.0+42`；发布标签：`v2.2.0`。线上更新要求目标 Release 已完整上传安装包及对应 `.sha256` 文件。
