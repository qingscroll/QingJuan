# 青卷 V2.2.1 更新日志

- 修复启用 TUN/Fake-IP DNS 的代理环境中，站点域名被解析到 `198.18.0.0/15` 后抓取请求被安全策略拒绝的问题。
- 检测到 Fake-IP 时通过固定公网地址访问加密 DNS，解析真实 A/AAAA 记录，同时保留 HTTPS 域名校验与连接 IP 固定。
- 加密 DNS 查询不继承系统代理、不跟随重定向；返回私网、环回、链路本地、Fake-IP 或混合不安全地址时继续拒绝连接。
- 公网解析失败时保持默认拒绝并给出代理 DNS 模式提示，不会直接放行虚拟地址。

应用版本：`2.2.1+43`；发布标签：`v2.2.1`。
